# Glossário técnico

Termos usados no código, nos relatórios e nos comentários traduzidos.

## Android e engenharia reversa

| Termo | Significado |
|---|---|
| **APK** | Pacote Android instalável; um ZIP com `classes*.dex`, recursos, bibliotecas nativas e assinatura. |
| **DEX** | Formato de bytecode executado pelo Android Runtime (ART). Este APK tem 17 arquivos. |
| **smali / baksmali** | Representação textual (smali) do bytecode DEX e a ferramenta que a produz (baksmali). É a forma **sem perdas** de ler e remontar o código. |
| **JADX** | Descompilador DEX → Java usado para leitura humana. O resultado é aproximado, não o código-fonte original. |
| **apktool** | Ferramenta que desmonta e remonta o APK (smali + recursos). |
| **aapt2** | Compilador/empacotador de recursos do Android; usado na remontagem e no `badging`. |
| **zipalign** | Alinha entradas do APK; obrigatório para bibliotecas nativas com `extractNativeLibs=false`. |
| **apksigner** | Assina e verifica APKs nos esquemas v1, v2, v3 e v3.1. |
| **D8 / R8** | Compilador DEX (D8) e otimizador/obfuscador (R8) do Android. A build original usou D8 8.9.35. |
| **minSdk / targetSdk** | Versão mínima do Android suportada (23) e versão de comportamento-alvo (35). |
| **debuggable** | Sinaliza que o app aceita depurador e `adb run-as`; não deve ser distribuído assim. |
| **cleartext** | Tráfego HTTP sem TLS. |
| **allowBackup** | Permite backup do diretório privado do app (nuvem e transferência entre aparelhos). |
| **Assinatura v1/v2/v3** | Esquemas de assinatura do APK. v1 assina entradas JAR; v2/v3 assinam o arquivo inteiro e habilitam rotação de chave. |
| **DTO** | Objeto de transferência de dados (aqui, classes Gson mapeadas para o JSON da API). |
| **ORDS** | Oracle REST Data Services — camada REST sobre o banco Oracle usada pelo back-end. |
| **MTR** | Manifesto de Transporte de Resíduos — documento regulatório brasileiro registrado pelo app. |
| **Bridge method** | Método sintético gerado pelo compilador para preservar polimorfismo após apagamento de tipos genéricos. |

## Marcadores do JADX nos comentários

O descompilador insere anotações em inglês; todas foram traduzidas na cópia `pt-BR/java`.

### Localização e renomeação

| Original | Tradução |
|---|---|
| `// from class: X` | `// da classe: X` |
| `/* loaded from: classesN.dex */` | `/* carregado de: classesN.dex */` |
| `/* renamed from: X, reason: ... */` | `/* renomeado de: X, motivo: ... */` |

### Motivos de renomeação (`reason`)

| Original | Tradução |
|---|---|
| invalid class name | nome de classe inválido |
| invalid class name and collision with other inner class name | nome de classe inválido e colisão com o nome de outra classe interna |
| not valid java name | nome Java inválido |
| not valid java name and from getter | nome Java inválido e de getter |
| collision with other inner class name | colisão com o nome de outra classe interna |
| collision with other method in class | colisão com outro método na classe |
| collision with root package name | colisão com o nome do pacote raiz |
| avoid collision after fix types in other method | evitar colisão após correção de tipos em outro método |
| merged with bridge method [inline-methods] | mesclado com método bridge [métodos inline] |
| from getter | de getter |
| from toString | de toString |
| from kotlin metadata | de metadados do Kotlin |
| from kotlin metadata and from toString | de metadados do Kotlin e de toString |

### Avisos informativos (`JADX INFO`)

| Original | Tradução |
|---|---|
| Access modifiers changed from: private / protected / package-private | modificadores de acesso alterados de: ... |
| Add missing generic type declarations: [T] | adicionar declarações de tipo genérico ausentes: [T] |
| This class is generated by JADX | esta classe foi gerada pelo JADX |

### Avisos de descompilação (`JADX WARN`)

| Original | Tradução |
|---|---|
| Can't fix incorrect switch cases order, some code will duplicate | não é possível corrigir a ordem dos casos do switch; parte do código será duplicada |
| Can't rename method to resolve collision | não é possível renomear o método para resolver a colisão |
| Can't wrap try/catch for region | não é possível envolver try/catch para a região |
| Failed to find 'out' block for switch in B | falha ao encontrar o bloco 'out' para o switch em B |
| Failed to restore enum class, 'enum' modifier and super class removed | falha ao restaurar a classe enum; modificador 'enum' e superclasse removidos |
| Failed to restore switch over string | falha ao restaurar o switch sobre string |
| Finally extract failed | falha na extração do bloco finally |
| Generic types in debug info not equals | tipos genéricos nas informações de depuração não são iguais |
| Illegal instructions before constructor call | instruções ilegais antes da chamada do construtor |
| Incorrect condition in loop | condição incorreta no laço |
| Incorrect field signature | assinatura de campo incorreta |
| Incorrect return type in method signature | tipo de retorno incorreto na assinatura do método |
| Incorrect types in method signature | tipos incorretos na assinatura do método |
| Multi-variable type inference failed | falha na inferência de tipos de múltiplas variáveis |
| Not initialized variable reg | variável não inicializada reg |
| Removed duplicated region for block | região duplicada removida para o bloco |
| 'super' call moved to the top of the method (can break code semantics) | chamada 'super' movida para o topo do método (pode alterar a semântica do código) |
| 'this' call moved to the top of the method (can break code semantics) | chamada 'this' movida para o topo do método (pode alterar a semântica do código) |
| Type inference failed for | falha na inferência de tipo para |
| Unknown enum class pattern. Please report as an issue! | padrão de classe enum desconhecido. Reporte como um problema! |
| Unknown type variable | variável de tipo desconhecida |
| Unreachable blocks removed | blocos inalcançáveis removidos |
| Unsupported multi-entry loop pattern | padrão de laço com múltiplas entradas não suportado |

## Convenções

- Palavras-chave e nomes de tipos Java (`private`, `switch`, `string`, `bridge method`) permanecem em inglês nos comentários, porque são referências de código.
- Endereços, offsets e identificadores (`B:43:0x00f1`, `r5v0`, `classes11.dex`) não são traduzidos.
- "Região", "bloco", "laço" e "sobrecarga" seguem a terminologia de compiladores em português.
